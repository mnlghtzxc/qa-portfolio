# Тестирование системы наград и квестов в мобильной игре

## 🎯 Цель
Продемонстрировать навыки тестирования клиент-серверных игровых механик: идемпотентность, синхронизация состояния, устойчивость к сетевым сбоям и анализ рисков игровой экономики.

## 📦 Что тестируем
Модуль «Квесты» мобильной игры. Модуль доступен с 7 уровня игрока.  
**Типы квестов:** стартовые, дня, недели.  
**Ключевые сущности:** прогресс, статусная модель, награда, таймер, баланс игрока (волшебные палочки, рубины, престиж, жетоны).  
**Архитектура:** клиент (UI, анимации, локальное отображение) → сервер (логика, валидация, хранение, выдача наград, таймеры).

## 🧪 Особенности тест-дизайна

- **Разделение ответственности клиент/сервер:** источник истины — сервер. Клиент только отображает состояние.
- **Тестирование идемпотентности:** мультитап по кнопке «Получить награду», гонки запросов.
- **Проверка атомарности:** награда либо начислена полностью, либо не начислена вовсе.
- **Сетевые аномалии:** обрыв связи в момент получения награды, реконнект, смена WiFi→мобильная сеть, VPN.
- **Манипуляции со временем:** перевод системных часов, смена часового пояса — таймеры не должны зависеть от устройства.
- **Граничные значения прогресса:** 0%, 99%, 100%, 101%.
- **Интеграционное тестирование:** связь модуля квестов с HUD, мини-играми, балансом игрока.

## 📊 Покрытие

### Функциональное тестирование (15+ кейсов)

| Категория                 | Позитивные сценарии                                     | Негативные / граничные                                         |
|---------------------------|---------------------------------------------------------|----------------------------------------------------------------|
| Прогресс квеста           | Начисление после релевантного действия, инкремент до 100% | Переполнение (>100%), потеря прогресса при реконнекте, начисление без серверной валидации |
| Статусная модель          | Переходы: Активен → В процессе → Награда доступна → Получена | Застревание в «В процессе» при 100% прогрессе, невалидный переход при неполном прогрессе |
| Начисление награды        | Одиночное получение, обновление баланса в HUD           | Мультитап, обрыв связи в момент получения, повторный запрос после реконнекта |
| Таймеры                   | Обратный отсчёт, сброс после выдачи, обновление списка квестов | Перевод системных часов, смена часового пояса, реконнект после долгого оффлайн |
| Замена квестов            | Обновление после истечения таймера                      | Преждевременная замена, дублирование квестов                   |
| Интеграция с балансом     | Синхронизация валют с HUD после получения награды       | Рассинхрон при одновременном входе с двух устройств, потеря валюты при сбое |

### Нефункциональное тестирование

| Тип                  | Проверки                                                                 |
|----------------------|--------------------------------------------------------------------------|
| UI/UX                | Отображение прогресс-бара, статусов, отсутствие наложения элементов, соответствие макетам, читаемость при разных разрешениях и ориентациях |
| Производительность   | ФПС, нагрев, расход батареи при длительной сессии, потребление памяти после закрытия, поведение при низком заряде |
| Совместимость        | Синхронизация между Web и мобильным клиентом, одновременный вход с разных платформ |
| Сетевая устойчивость | Авиарежим, потеря сети, слабый сигнал, смена WiFi→4G, VPN              |
| Форматирование чисел | Отображение больших значений валют (формула сокращения), переполнение UI |

## 🐞 Ключевые баги

| ID      | Описание                                                                 | Серьёзность |
|---------|--------------------------------------------------------------------------|-------------|
| BUG-101 | Двойное начисление награды при быстром двойном тапе (мультитап)          | Критическая |
| BUG-102 | Потеря награды при обрыве соединения в момент получения — статус «Получена», баланс не изменился | Критическая |
| BUG-103 | Прогресс-бар показывает 100%, но кнопка «Получить» не появляется (рассинхрон статуса) | Высокая     |
| BUG-104 | Таймер квеста сбрасывается при переводе системных часов назад            | Высокая     |
| BUG-105 | Отрицательный баланс валюты при административной отмене награды          | Средняя     |

## 🧠 Анализ рисков (модуль «Квесты»)

| Группа рисков          | Описание                                                                 | Уровень |
|------------------------|--------------------------------------------------------------------------|---------|
| Технические            | Сбой серверной выдачи наград, рассинхронизация статусов, некорректное обновление списка квестов | Высокий |
| Игровая экономика      | Дублирование наград, получение без выполнения условий, преждевременный фарм | Высокий |
| UX                     | Отсутствие обратной связи после действия, непонятный статус доступности награды | Средний |
| Интеграционные         | Отсутствие события от мини-игры, рассинхрон HUD и серверного баланса     | Высокий |
