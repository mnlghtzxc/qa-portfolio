# Тестирование системы наград в мобильной игре

## 🎯 Цель
Продемонстрировать умение тестировать клиент-серверные игровые механики: идемпотентность операций, синхронизацию состояния, устойчивость к сетевым аномалиям и защиту игровой экономики.

## 📦 Что тестируем
Модуль ежедневных/еженедельных квестов условно-бесплатной мобильной игры.  
**Ключевые сущности:** прогресс квеста, награда, таймер, статусная модель.  
**Архитектура:** клиент (UI, локальный счётчик прогресса) → сервер (логика, валидация, начисление, хранение).

## 🧪 Особенности тест-дизайна
- Разделение ответственности клиент/сервер: все проверки строились вокруг того, что **источник истины — сервер**
- Тестирование идемпотентности: мультитап, повторные запросы, гонки запросов
- Проверка сетевых сбоев: обрыв соединения в момент получения награды, восстановление таймера после реконнекта
- Манипуляции с локальным временем: перевод системных часов для проверки серверного контроля таймеров

## 📊 Покрытие (15 тест-кейсов)

| Категория              | Позитивные сценарии                        | Негативные / граничные                              | Статус |
|------------------------|--------------------------------------------|-----------------------------------------------------|--------|
| Прогресс квеста        | Заполнение до 100%, корректный инкремент   | Переполнение, потеря прогресса при реконнекте        | ✅     |
| Начисление награды     | Одиночное получение, проверка баланса     | Мультитап (двойное нажатие), обрыв связи при получении, повторный запрос | ✅     |
| Таймеры                | Корректный обратный отсчёт, сброс после выдачи | Перевод системных часов назад, реконнект после долгого оффлайн | ✅     |
| Статусная модель       | Переходы: «В процессе» → «Награда доступна» → «Награда получена» | Застревание в «В процессе» при 100% прогрессе (рассинхрон) | ✅     |
| UI/UX                  | Отображение прогресса, кнопок, таймеров    | Длинные названия квестов, специальные символы, вёрстка при разных разрешениях | ✅     |
