# Сценарий 1. Эмуляция ошибки сервера (503 Service Unavailable)

## Цель

Проверить поведение клиента при недоступности сервера.

## Инструмент

Charles Proxy (Rewrite Rule)

## Действия

Для запроса к тестовому endpoint выполнена подмена HTTP-статуса:

* исходный ответ: 200 OK
* изменённый ответ: 503 Service Unavailable

## Ожидаемый результат

Клиент получает сообщение об ошибке и не обрабатывает ответ как успешный.

## Фактический результат

После применения Rewrite клиент получил ответ со статусом 503.

## Вывод

Charles Proxy позволяет эмулировать ошибки сервера без внесения изменений в backend и использовать такие сценарии для проверки обработки ошибок на стороне клиента.
