# Анализ и отладка клиент-серверного взаимодействия

## Цель проекта

Практика анализа сетевого трафика и диагностики проблем клиент-серверного взаимодействия с использованием Chrome DevTools и Charles Proxy.

В рамках проекта выполнены:

- анализ HTTP/HTTPS запросов;
- исследование Request и Response;
- работа с HAR-файлами;
- перехват HTTPS-трафика;
- изменение запросов и ответов;
- эмуляция ошибок сервера;
- подмена ответов локальными данными.

---

## Инструменты

- Chrome DevTools
- Charles Proxy
- JSONPlaceholder API
- Httpbin

---

## Выполненные сценарии

### DevTools

- фильтрация XHR/Fetch запросов;
- анализ заголовков;
- анализ тела запроса;
- анализ тела ответа;
- экспорт HAR-файла.

### Charles Proxy

- SSL Proxying;
- Breakpoints;
- Rewrite Rules;
- Map Local.

## Полученные навыки

- анализ сетевого трафика;
- локализация проблем между клиентом и сервером;
- работа с HTTP-статусами;
