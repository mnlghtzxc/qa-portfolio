# Анализ сетевого трафика в Chrome DevTools

## Цель

Изучить структуру HTTP-запросов и ответов, а также получить практический опыт работы с инструментом Network в Chrome DevTools.

## Используемый API

JSONPlaceholder

## Выполненные действия

В ходе анализа были выполнены следующие запросы:

* GET /posts
* GET /posts/1
* GET /users/1
* GET /comments?postId=1

Для каждого запроса были исследованы:

* URL запроса;
* HTTP-метод;
* статус ответа;
* заголовки запроса и ответа;
* структура JSON-ответа.

## Результаты

В результате анализа установлено:

* запросы успешно обрабатываются сервером;
* ответы возвращаются в формате JSON;
* для успешных запросов используется статус 200 OK;
* структура данных соответствует документации API.
