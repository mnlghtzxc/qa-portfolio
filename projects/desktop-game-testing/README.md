# Исследовательское тестирование 3D-шутера (без спецификации)

## 🎯 Цель
Показать навыки исследовательского тестирования в условиях отсутствия документации: декомпозиция системы, поиск уязвимых стыков, формулировка root cause без доступа к коду.

## 📦 Что тестируем
Автономный 3D-шутер от первого лица под Windows (сборка `kkrieger-beta`). Процедурная генерация уровней, 5 видов оружия, враги с простым ИИ, управление с клавиатуры и мыши. Никаких требований и спецификаций — только билд.

## 🧪 Особенности тест-дизайна
- **Декомпозиция на системы:** передвижение/физика, оружие/ввод, ИИ/навигация, графика/стабильность, UI/меню
- **Фокус на стыках систем:** смена оружия во время прыжка, удержание огня при переключении, анимация открытия двери vs коллизия, поведение врагов при вызове меню
- **Root cause анализ:** для каждого бага определялась вероятная причина на уровне логики движка, без доступа к исходному коду
- **Исследовательские туры:** обход уровней, провокация краевых условий, стресс-тесты ввода

## 📊 Покрытие

| Система               | Проверено                                         | Найденные баги                 |
|-----------------------|---------------------------------------------------|--------------------------------|
| Передвижение / физика | Коллизии с объектами, прыжки, ускорение, телепортация | Прохождение сквозь дверь (стык анимации и коллизии) |
| Оружие / ввод         | Переключение оружия, удержание огня, стрельба в прыжке | Прекращение стрельбы после смены оружия при зажатой ЛКМ |
| ИИ врагов             | Преследование, обход препятствий, реакция на меню | Застревание в геометрии «Корни», движение врагов при открытом меню |
| Графика / стабильность| Alt+Tab, смена разрешения, полноэкранный/оконный режим | Зависание при сворачивании (Alt+Tab из fullscreen) |
| UI / меню             | Навигация, настройки, пауза                       | Некорректный сброс настроек после перезапуска (мелкий баг) |

Всего оформлено **10 багов**, большинство стабильно воспроизводятся.

## 🐞 Примеры оформленных багов

**BUG-201: Прохождение сквозь дверь во время анимации открытия**  
Серьёзность: Средняя | Статус: Открыт  
*Root cause:* состояние коллизии («открыто») включается по триггеру, а не по окончании анимации. Синхронизация анимации и физики отсутствует.

**BUG-202: Застревание врага в объекте «Корни»**  
Серьёзность: Высокая | Статус: Открыт  
*Root cause:* навигационная сетка не учитывает вогнутую форму объекта, алгоритм обхода не справляется.

## 🧰 Инструменты
Ручное тестирование, OBS (запись видео багов), системный мониторинг (отслеживание зависаний), анализ логов Windows (Event Viewer).
