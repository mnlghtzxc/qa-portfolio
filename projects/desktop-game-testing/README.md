# Desktop Game Testing

# Тестирование 3D‑шутера kkrieger‑beta

**Тип проекта**: исследовательское тестирование локального приложения  
**Окружение**: Windows 11, Fullscreen (2560×1440), CPU Intel 12400, GPU 3070 Ti, 32 ГБ ОЗУ  
**Цель**: проверка базовых механик, коллизий, поведения ИИ (искусственного интеллекта врагов), стабильности и обработки пользовательского ввода

## Объект тестирования
kkrieger‑beta — автономный 3D‑шутер от первого лица с процедурной генерацией контента.  
Управление: клавиатура + мышь. Телепортация по клавишам M1–M9.  
Игровые системы: передвижение, стрельба, получение урона, подбор предметов, переключение оружия, HUD, враги с простым ИИ, двери с триггерами, коллизии, камера, меню.

## Результаты
Найдено и оформлено **10 багов** с указанием шагов воспроизведения, ожидаемого/фактического результата, критичности, приоритета и воспроизводимости. Для части дефектов определена вероятная корневая причина.

### Избранные баг‑репорты (все 10 доступны в полной версии)

**1. Прохождение сквозь дверь во время анимации открытия**
- **Критичность**: средняя | **Приоритет**: средний
- **Воспроизводимость**: стабильно
- **Шаги**: подойти к двери, активировать триггер открытия, в момент начала анимации попытаться пройти вперёд.
- **Фактический результат**: игрок проходит сквозь дверь до её полного открытия.
- **Ожидаемый результат**: коллизия блокирует проход до конца анимации.
- **Root cause**: состояние коллизии двери («открыто») изменяется в момент срабатывания триггера, а не по завершении анимации. Синхронизация анимации и физического коллайдера отсутствует.

**2. Зависание при Alt+Tab из полноэкранного режима**
- **Критичность**: высокая | **Приоритет**: высокий
- **Шаги**: запустить игру в fullscreen, нажать Alt+Tab.
- **Фактический результат**: игра зависает, процесс не отвечает.
- **Root cause**: вероятно, некорректная обработка события потери/восстановления графического контекста DirectX при сворачивании — нет механизма перезагрузки ресурсов или корректного выхода из полноэкранного режима.

**3. Застревание врага в геометрии объекта «Корни»**
- **Критичность**: высокая | **Приоритет**: высокий
- **Шаги**: спровоцировать врага, завести его за объект «Корни» так, чтобы он попытался обойти препятствие.
- **Фактический результат**: враг застревает, преследование прекращается.
- **Root cause**: навигационная сетка (NavMesh) не учитывает сложную геометрию объекта, либо алгоритм обхода упрощён и не справляется с вогнутыми формами.

**4. Прекращение стрельбы после переключения оружия при удержании ЛКМ**
- **Критичность**: средняя | **Приоритет**: средний
- **Шаги**: зажать левую кнопку мыши (огонь), не отпуская, переключить оружие (клавиши 1–5).
- **Фактический результат**: после переключения происходит одиночный выстрел, затем стрельба прекращается.
- **Root cause**: состояние ввода (удержание кнопки) не переподписывается на новое оружие — система ожидает нового нажатия после смены.

## Общие выводы
Основная масса дефектов связана с:
- **Коллизиями и анимациями** — расхождение визуального отображения и физической модели (двери, колонны).
- **Обработкой состояний ввода** — игнорирование удержания клавиш после смены оружия, задержки в прыжке.
- **ИИ и навигацией** — враги застревают в геометрии, не прекращают движение при вызове меню.
- **Стабильностью** — отсутствие устойчивости к системным событиям (Alt+Tab).

Проект демонстрирует умение проводить исследовательское тестирование в условиях отсутствия документации, выявлять скрытые дефекты коллизий и логики состояний, а также формулировать предположения о корневых причинах (root cause analysis).
