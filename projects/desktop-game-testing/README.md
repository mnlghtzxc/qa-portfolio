# Исследовательское тестирование 3D-шутера kkrieger-beta

Досталась сборка автономного шутера от первого лица под Windows без документации. Процедурная генерация контента, пять видов оружия, враги с простым ИИ, управление с клавиатуры и мыши. Задача — найти баги, связанные с механиками, коллизиями и стабильностью.

## Как исследовал
Прошёлся по всем системам: передвижение, стрельба, смена оружия, взаимодействие с предметами (здоровье, патроны), телепортация, поведение врагов. Сразу обращал внимание на стыки систем — например, переключение оружия во время прыжка или удержание огня при смене оружия. Смотрел, как двери обрабатывают коллизию во время анимаций, как AI обходит препятствия.

## Примеры найденных багов (всего оформил 10)

**Зависание при Alt+Tab из полноэкранного режима**
- Шаги: запустить игру в fullscreen, нажать Alt+Tab.
- Фактический результат: игра зависает, процесс не отвечает.
- Ожидаемый результат: игра сворачивается и восстанавливается без потери работоспособности.
- Приоритет: высокий. Баг стабильный, предположительная причина — нет перезагрузки графического контекста DirectX.

**Прохождение сквозь дверь во время анимации открытия**
- Шаги: подойти к двери, активировать триггер открытия, в момент начала анимации попытаться пройти вперёд.
- Фактический результат: персонаж проходит сквозь дверь до её полного открытия.
- Ожидаемый результат: коллизия блокирует проход до конца анимации.
- Причина: состояние коллизии «открыто» включается по срабатыванию триггера, а не по завершении анимации.

**Застревание врага в объекте «Корни»**
- Шаги: спровоцировать врага, завести за объект «Корни» так, чтобы он попытался обойти препятствие.
- Фактический результат: враг застревает в геометрии, преследование прекращается.
- Приоритет: высокий. Вероятно, навигационная сетка не учитывает вогнутые формы объекта.

**Прекращение стрельбы после смены оружия с зажатой ЛКМ**
- Шаги: зажать левую кнопку мыши (огонь), не отпуская, переключить оружие клавишами 1-5.
- Фактический результат: происходит одиночный выстрел, затем стрельба прекращается.
- Ожидаемый результат: стрельба продолжается с новым оружием.
- Причина: состояние удержания кнопки не передаётся новому оружию, система ждёт нового нажатия.

## Выводы
Понял, как тестировать без спецификации: опираться на ожидаемое поведение игровых механик и здравый смысл. Научился различать баги коллизий, состояния ввода и AI, формулировать root cause без доступа к коду. Большинство проблем вылезло на стыке систем — это теперь первое, куда смотрю в играх.
