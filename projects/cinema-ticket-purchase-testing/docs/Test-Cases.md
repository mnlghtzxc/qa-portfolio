# Test Cases — Cinema Ticket Purchase API

## Клиентские сценарии

| ID | Название | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|---|
| 1 | Получить список сеансов | Сервер запущен, `base_url` = `http://localhost:5000/api/v1`. В базе есть минимум один сеанс. | 1. Отправить GET-запрос на `{{base_url}}/sessions`. | Статус-код 200. Тело содержит массив `sessions`. Каждый элемент включает поля: `session_id` (int), `movie` (string), `hall` (string), `free_seats` (int >= 0), `start_time` (string). |
| 2 | Купить билет (позитивный) | Есть сеанс со свободными местами, зарегистрированный пользователь `user_id=1`. | 1. Отправить POST-запрос на `{{base_url}}/tickets/purchase` с телом `{"session_id":1,"user_id":1}`. | Статус-код 201. Тело содержит объект `ticket` с полями: `id` (int), `status` = "purchased", `price` (число > 0, равно `base_price` зала). В БД запись о билете с `status='purchased'`, количество свободных мест на сеанс уменьшилось на 1. |
| 3 | Купить билет (негативный: нет session_id) | Сервер запущен. | 1. Отправить POST-запрос на `{{base_url}}/tickets/purchase` с телом `{"user_id":1}`. | Статус-код 400. Тело содержит `error` с текстом о необходимости `session_id`. |
| 4 | Купить билет (негативный: несуществующий сеанс) | Сервер запущен. | 1. Отправить POST-запрос на `{{base_url}}/tickets/purchase` с телом `{"session_id":999,"user_id":1}`. | Статус-код 404. Тело содержит `error` = "Session not found". |
| 5 | Вернуть билет (позитивный) | Есть билет со статусом `purchased` на будущий сеанс. | 1. Отправить POST-запрос на `{{base_url}}/tickets/{id}/refund`, где `{id}` – ID билета. | Статус-код 200. Тело содержит `ticket` с `status` = "refund". В БД статус билета изменился на `refund`, количество свободных мест на сеанс увеличилось на 1. |
| 6 | Вернуть билет (негативный: повторный возврат) | Есть билет, который уже вернули (статус `refund`). | 1. Отправить POST-запрос на `{{base_url}}/tickets/{id}/refund`, где `{id}` – ID того же билета. | Статус-код 400. Тело содержит `error` с упоминанием текущего статуса (`refund`). |
| 7 | Получить билеты пользователя | Зарегистрированный пользователь `user_id=1` имеет хотя бы один билет. | 1. Отправить GET-запрос на `{{base_url}}/users/1/tickets`. | Статус-код 200. Тело содержит массив `tickets`. Каждый элемент включает `ticket_id`, `session_id`, `movie`, `hall`, `start_time`, `end_time`, `price`, `status`. |
| 8 | Получить билеты пользователя (негативный: пользователь не найден) | Сервер запущен. | 1. Отправить GET-запрос на `{{base_url}}/users/999/tickets`. | Статус-код 404. Тело содержит `error` = "User not found". |

## Административные сценарии

| ID | Название | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|---|
| 9 | Получить список залов | Сервер запущен. | 1. Отправить GET-запрос на `{{base_url}}/admin/halls`. | Статус-код 200. Тело содержит массив `halls`. |
| 10 | Создать зал | Сервер запущен. | 1. Отправить POST-запрос на `{{base_url}}/admin/halls` с телом `{"name":"Lounge","capacity":15,"base_price":1200.00}`. | Статус-код 201. Тело содержит `hall` с переданными параметрами. В БД новая запись в таблице `halls`. |
| 11 | Удалить зал без сеансов | Есть зал без сеансов. | 1. Отправить DELETE-запрос на `{{base_url}}/admin/halls/{id}`. | Статус-код 200. Зал удалён из БД. |
| 12 | Удалить зал с сеансами (негативный) | В базе есть зал с id=3 (VIP), на который запланирован хотя бы один сеанс. | 1. Отправить DELETE-запрос на `{{base_url}}/admin/halls/3`. | Статус-код 409. Тело содержит `error` о невозможности удаления. В БД зал остался без изменений. |
| 13 | Получить список фильмов | Сервер запущен. | 1. Отправить GET-запрос на `{{base_url}}/admin/movies`. | Статус-код 200. Тело содержит массив `movies`. |
| 14 | Добавить фильм | Сервер запущен. | 1. Отправить POST-запрос на `{{base_url}}/admin/movies` с телом `{"title":"Interstellar","duration_minutes":169,"genre":"Sci-Fi"}`. | Статус-код 201. Тело содержит `movie` с переданными параметрами. В БД новая запись в таблице `movies`. |
| 15 | Обновить фильм (PATCH) | Есть фильм с id=2 (Matrix). | 1. Отправить PATCH-запрос на `{{base_url}}/admin/movies/2` с телом `{"title":"New Title"}`. | Статус-код 200. Название фильма обновлено в ответе и в БД. |
| 16 | Удалить фильм без сеансов | Есть фильм без связанных сеансов. | 1. Отправить DELETE-запрос на `{{base_url}}/admin/movies/{id}`. | Статус-код 200. Фильм удалён из БД. |
| 17 | Удалить фильм с сеансами (негативный) | В базе есть фильм с id=1 (Lord of the Rings), на который запланирован хотя бы один сеанс. | 1. Отправить DELETE-запрос на `{{base_url}}/admin/movies/1`. | Статус-код 409. Тело содержит `error` о невозможности удаления. В БД фильм остался без изменений. |
| 18 | Создать сеанс | Есть фильм (id=2) и зал (id=2) без пересекающихся сеансов. | 1. Отправить POST-запрос на `{{base_url}}/admin/sessions` с телом `{"movie_id":2,"hall_id":2,"start_time":"2027-07-01 18:00:00"}`. | Статус-код 201. Тело содержит `session` с вычисленным `end_time`. В БД новая запись в таблице `sessions`. |
| 19 | Создать сеанс с пересечением (негативный) | В зале с id=2 (3D) уже есть сеанс на 2027-07-01 18:00:00 (создан в предыдущем кейсе). | 1. Отправить POST-запрос на `{{base_url}}/admin/sessions` с телом `{"movie_id":3, "hall_id":2, "start_time":"2027-07-01 18:30:00"}`. | Статус-код 409. Тело содержит `error` о занятости зала. В БД сеанс не создан. |
| 20 | Удалить сеанс без билетов | Есть сеанс без купленных билетов. | 1. Отправить DELETE-запрос на `{{base_url}}/admin/sessions/{id}`. | Статус-код 200. Сеанс удалён из БД. |
| 21 | Удалить сеанс с билетами (негативный) | Есть сеанс с проданными билетами (id=1). | 1. Отправить DELETE-запрос на `{{base_url}}/admin/sessions/1`. | Статус-код 409. Тело содержит `error` о наличии активных билетов. В БД сеанс остался без изменений. |
