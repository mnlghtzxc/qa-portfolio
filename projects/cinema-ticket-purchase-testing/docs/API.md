## Обзор

| Параметр       | Значение                       |
| -------------- | ------------------------------ |
| Версия API     | `v1`                           |
| Базовый URL    | `http://localhost:5000/api/v1` |
| Формат данных  | `JSON`                         |
| Аутентификация | Не требуется                   |

---

## Аутентификация

На текущий момент API не требует авторизации.

---

## Модель предметной области

### Зал (Hall)

- название  
- вместимость  
- базовая стоимость билета  

### Фильм (Movie)

- название  
- жанр  
- продолжительность  

### Сеанс (Session)

Показ фильма в определённом зале и в заданное время.

### Билет (Ticket)

| Статус    | Описание          |
|-----------|-------------------|
| purchased | Билет куплен      |
| used      | Билет использован |
| refund    | Билет возвращён   |

## Клиентские эндпоинты

### Получить список сеансов

**GET** `/sessions`

Возвращает список доступных сеансов.  
Свободные места вычисляются как `capacity - количество билетов со статусами purchased или used`.

#### Параметры запроса

| Параметр | Тип     | Обязательный | Описание                     |
|----------|---------|--------------|------------------------------|
| movie_id | integer | Нет          | Фильтр по ID фильма *(в планах)* |
| date     | string  | Нет          | Фильтр по дате `YYYY-MM-DD` *(в планах)* |

#### Пример запроса

```bash
curl http://localhost:5000/api/v1/sessions
```

#### Ответ 200

```json
{
  "sessions": [
    {
      "session_id": 1,
      "movie": "The Lord of the Rings",
      "duration_minutes": 176,
      "hall": "IMAX",
      "capacity": 50,
      "tickets_sold": 3,
      "free_seats": 47,
      "start_time": "2027-06-11 20:00:00",
      "end_time": "2027-06-11 22:56:00"
    }
  ]
}
```

| Код | Описание       |
|-----|----------------|
| 200 | Список сеансов |

### Купить билет

**POST** `/tickets/purchase`

Создаёт билет на выбранный сеанс. Цена определяется автоматически по базовой цене зала.  
Необходимо передать **либо** `user_id`, **либо** `email`, но не оба одновременно.

#### Тело запроса (зарегистрированный пользователь)

```json
{
  "session_id": 1,
  "user_id": 1
}
```

#### Тело запроса (гость)

```json
{
  "session_id": 1,
  "email": "guest@example.com"
}
```

#### Ответ 201

```json
{
  "message": "Ticket purchased successfully",
  "ticket": {
    "id": 5,
    "session_id": 1,
    "customer_id": 3,
    "price": 500.0,
    "status": "purchased",
    "created_at": "2026-06-11 15:49:01"
  }
}
```

#### Коды ответов

| Код | Описание                         |
|-----|----------------------------------|
| 201 | Билет успешно куплен             |
| 400 | Ошибка валидации                 |
| 404 | Сеанс или пользователь не найден |
| 409 | Нет свободных мест               |

---

### Вернуть билет

**POST** `/tickets/{ticket_id}/refund`

Меняет статус билета на `refund`.  
Возврат возможен только для билетов в статусе `purchased` и до начала сеанса.

#### Параметры пути

| Параметр  | Тип     | Описание  |
|-----------|---------|-----------|
| ticket_id | integer | ID билета |

#### Пример запроса

```bash
curl -X POST http://localhost:5000/api/v1/tickets/4/refund
```

#### Ответ 200

```json
{
  "message": "Ticket refunded successfully",
  "ticket": {
    "id": 4,
    "status": "refund"
  }
}
```

#### Возможные ошибки

```json
{ "error": "Ticket cannot be refunded. Current status: used" }
```

```json
{ "error": "Cannot refund ticket: session has already started" }
```

```json
{ "error": "Ticket not found" }
```

| Код | Описание                                     |
|-----|----------------------------------------------|
| 200 | Возврат выполнен                             |
| 400 | Неверный статус билета или сеанс уже начался |
| 404 | Билет не найден                              |

---

### Получить билеты пользователя

**GET** `/users/{user_id}/tickets`

Возвращает список билетов, приобретённых зарегистрированным пользователем.

#### Параметры пути

| Параметр | Тип     |
|----------|---------|
| user_id  | integer |

#### Ответ 200

```json
{
  "user_id": 1,
  "tickets": [
    {
      "ticket_id": 4,
      "session_id": 1,
      "movie": "The Lord of the Rings",
      "hall": "IMAX",
      "start_time": "2027-06-11 20:00:00",
      "end_time": "2027-06-11 22:56:00",
      "price": 500.0,
      "status": "refund",
      "purchased_at": "2026-06-11 15:48:45"
    }
  ]
}
```

| Код | Описание                    |
|-----|-----------------------------|
| 200 | Список билетов пользователя |
| 404 | Пользователь не найден      |

## Административные эндпоинты

### Залы

#### GET `/admin/halls`

Возвращает список всех залов.

| Код | Описание     |
|-----|--------------|
| 200 | Список залов |

#### POST `/admin/halls`

Создаёт новый зал.

```json
{
  "name": "Lounge",
  "capacity": 15,
  "base_price": 1200.00
}
```

| Код | Описание         |
|-----|------------------|
| 201 | Зал создан       |
| 400 | Ошибка валидации |

#### DELETE `/admin/halls/{hall_id}`

Удаляет зал, если на него нет сеансов.

| Код | Описание                   |
|-----|----------------------------|
| 200 | Зал удалён                 |
| 404 | Зал не найден              |
| 409 | Для зала существуют сеансы |

---

### Фильмы

#### GET `/admin/movies`

Возвращает список всех фильмов.

| Код | Описание       |
|-----|----------------|
| 200 | Список фильмов |

#### POST `/admin/movies`

Создаёт новый фильм.

```json
{
  "title": "Interstellar",
  "duration_minutes": 169,
  "genre": "Sci-Fi"
}
```

| Код | Описание         |
|-----|------------------|
| 201 | Фильм создан     |
| 400 | Ошибка валидации |

#### PATCH `/admin/movies/{movie_id}`

Частично обновляет фильм. Допустимые поля: `title`, `duration_minutes`, `genre`.

```json
{
  "title": "The Lord of the Rings"
}
```

| Код | Описание        |
|-----|-----------------|
| 200 | Фильм обновлён  |
| 404 | Фильм не найден |

#### DELETE `/admin/movies/{movie_id}`

Удаляет фильм, если на него нет сеансов.

| Код | Описание                    |
|-----|-----------------------------|
| 200 | Фильм удалён                |
| 404 | Фильм не найден             |
| 409 | Существуют связанные сеансы |

---

### Сеансы

#### POST `/admin/sessions`

Создаёт новый сеанс.  
`end_time` вычисляется автоматически: `start_time + duration_minutes` фильма.  
Зал не должен быть занят другим сеансом в это же время.

```json
{
  "movie_id": 2,
  "hall_id": 2,
  "start_time": "2027-06-12 20:00:00"
}
```

| Код | Описание                |
|-----|-------------------------|
| 201 | Сеанс создан            |
| 400 | Неверный формат даты    |
| 404 | Фильм или зал не найден |
| 409 | Зал занят               |

#### DELETE `/admin/sessions/{session_id}`

Удаляет сеанс, если на него нет купленных билетов (статусы `purchased` или `used`).

| Код | Описание             |
|-----|----------------------|
| 200 | Сеанс удалён         |
| 404 | Сеанс не найден      |
| 409 | Есть активные билеты |

## Бизнес-правила

- Цена билета равна `base_price` выбранного зала  
- Можно передать только одно из: `user_id` или `email`  
- Нельзя продать больше билетов, чем вместимость зала  
- Возврат билета разрешён только до начала сеанса  
- Сеансы в одном зале не могут пересекаться по времени  

---

## Правила валидации

### Зал
- `capacity > 0`  
- `base_price > 0`  

### Фильм
- `duration_minutes > 0`  

### Сеанс
- Корректные `movie_id` и `hall_id`  
- Валидный формат `start_time` (`YYYY-MM-DD HH:MM:SS`)  

### Покупка билета
- `session_id` обязателен  
- Ровно одно из полей: `user_id` или `email`  

---

## Правила целостности данных

- `users.email` — уникальный  
- В таблице `customers` действует частичный уникальный индекс: `email` уникален только для зарегистрированных (`user_id IS NOT NULL`). Анонимные покупатели могут иметь повторяющиеся email.  
- `price > 0`  
- `capacity > 0`  
- `duration_minutes > 0`  

### Защита от гонок

```sql
SELECT ... FOR UPDATE
```

Используется при покупке билета, чтобы предотвратить перепродажу мест при одновременных запросах.

### Проверка пересечения сеансов

```sql
existing.start_time < new.end_time
AND existing.end_time > new.start_time
```

| Код | Значение                  |
|-----|---------------------------|
| 200 | Успешный запрос           |
| 201 | Ресурс успешно создан     |
| 400 | Ошибка валидации данных   |
| 404 | Ресурс не найден          |
| 409 | Конфликт бизнес-логики    |
| 500 | Внутренняя ошибка сервера |

---

## Типичные случаи 409 Conflict

- Нет свободных мест  
- Зал занят другим сеансом  
- Нельзя удалить зал с существующими сеансами  
- Нельзя удалить фильм с существующими сеансами  
- Нельзя удалить сеанс с активными билетами (статусы `purchased` или `used`)
