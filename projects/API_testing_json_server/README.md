# Тестирование API json-server
Практический проект по тестированию REST API на локальном JSON Server с собственной серверной валидацией.

## Что тестируем
- Тестовый сервер на базе json-server с кастомной валидацией
- REST API для сущности Post

## Как запустить
1. Установить json-server глобально: npm install -g json-server
2. Скопировать репозиторий
3. Запустить сервер: node server.js
4. Импортировать коллекцию и окружение в Postman

## Структура коллекции
- CRUD (позитивные E2E) — цепочка проверок полного жизненного цикла поста
- Негативные тесты — для каждого метода: проверка граничных условий, валидаций, 404 ошибок

## Техники и инструменты
- Переменные окружения в Postman
- Pre-request и Test-скрипты
- Проверка контракта ошибок
- E2E-сценарий
