# Network Debugging Lab

Проект демонстрирует навыки сетевой отладки: анализ трафика через DevTools и активное вмешательство через Charles Proxy.

## Структура
- `devtools/` — артефакты пассивного анализа (HAR, скриншоты, разбор)
- `charles/` — артефакты активного проксирования (скриншоты, конфиги)

## Инструменты
- Chrome DevTools Network
- Charles Proxy 5.1

## Ключевые сценарии
- Фильтрация XHR/Fetch, чтение статусов и заголовков
- Анализ CORS-ошибок
- Отделение бизнес-API от трекеров
- Перехват и модификация HTTPS-трафика (Breakpoints)
- Автоматическая подмена (Rewrite: заголовки, статусы, параметры)
- Подмена ответа локальным файлом (Map Local)

## Как использовать
- HAR-файл можно импортировать в DevTools для повторного анализа.
- Правила Charles описаны в charles-config.md, могут быть воссозданы.
