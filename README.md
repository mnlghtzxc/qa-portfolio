# QA Portfolio — Михтеев Владислав

QA-инженер с опытом работы в продуктах с многомиллионной аудиторией. Основной интерес - тестирование API, backend-систем и работа с данными. Развиваю навыки SQL, клиент-серверной архитектуры и автоматизации тестирования. В GitHub-портфолио представлены практические проекты.

## Ключевые компетенции (подтверждено проектами)
- Разработка и автоматизация API-тестов в Postman (позитивные/негативные сценарии, E2E-цепочки)
- Написание SQL-запросов для проверки целостности данных (JOIN, подзапросы, транзакции)
- Тестирование клиент-серверного взаимодействия через Charles и DevTools
- Smoke-тестирование API из командной строки с помощью curl и bash

## 🛠️ Инструменты и навыки
**API-тестирование:** Postman (коллекции, переменные окружения, скрипты), Charles (перехват, подмена), DevTools (Network, Console), curl + grep (ручные smoke-проверки), bash-скрипты (базово)  
**Работа с данными:** SQL (SQLite, PostgreSQL) — JOIN, агрегация, подзапросы, транзакции  
**Мобильное тестирование:** Android Studio (эмулятор, логи), Xcode (симулятор)  
**Баг-трекинг:** YouTrack, YandexTracker

- **[SQL для QA: проверка целостности данных и анализ](./projects/sql-sqlite/README.md)**  
  Проектирование таблиц, ограничения целостности, JOIN'ы, подзапросы, транзакции, поиск орфанных записей.  
  **Инструменты:** SQLite, консольный клиент.

  Анализ HTTP/HTTPS-трафика через DevTools и Charles Proxy, перехват запросов, подмена ответов, эмуляция ошибок сервера.
  **Инструменты:** Chrome DevTools, Charles Proxy.

- **[Linux CLI Smoke-тесты API: автоматическая проверка работоспособности эндпоинтов](./projects/linux-cli-api-smoke/README.md)**

  **Инструменты:** Bash, curl, grep, cut, sed.

- **[Docker для QA: тестовый стенд API + PostgreSQL](./projects/docker-api-postgres/README.md)**  
  Развёртывание микросервисного тестового окружения с нуля: написание Dockerfile для Flask-приложения, связывание API с базой данных PostgreSQL через Docker Compose, инициализация схемы данных, проверка сохранности данных между перезапусками, анализ логов.  
  **Инструменты:** Docker, Docker Compose, Flask, PostgreSQL, curl.

- **[Комплексное тестирование сервиса доставки: веб, API и мобильное приложение](./projects/delivery-service-testing/README.md)**
