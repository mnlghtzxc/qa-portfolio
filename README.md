# QA Portfolio — Михтеев Владислав

QA-инженер с опытом работы в продуктах с многомиллионной аудиторией. Основной интерес - тестирование API, backend-систем и работа с данными. Развиваю навыки SQL, клиент-серверной архитектуры и автоматизации тестирования. В GitHub-портфолио представлены практические проекты.

## 🧠 Ключевые компетенции (подтверждено проектами)
- Разработка и автоматизация API-тестов в Postman (позитивные/негативные сценарии, E2E-цепочки)
- Написание SQL-запросов для проверки целостности данных (JOIN, подзапросы, транзакции)
- Тестирование клиент-серверного взаимодействия через Charles и DevTools
- Smoke-тестирование API из командной строки с помощью curl и bash
- Настройка CI/CD (GitHub Actions) для автоматического запуска тестов

## 🛠️ Инструменты и навыки
**API-тестирование:** Postman (коллекции, переменные окружения, скрипты), Charles (перехват, подмена), DevTools (Network, Console), curl + grep (ручные smoke-проверки), bash-скрипты (базово)  
**Работа с данными:** SQL (SQLite, PostgreSQL) — JOIN, агрегация, подзапросы, транзакции  
**Мобильное тестирование:** Android Studio (эмулятор, логи), Xcode (симулятор)  
**Баг-трекинг:** YouTrack, YandexTracker  
**Контроль версий и CI/CD:** Git (ветвление, слияние, разрешение конфликтов), GitHub (Pull Requests, Actions). Пример: [репозиторий git-practice](https://github.com/mnlghtzxc/qa-git-practice) с историей коммитов и рабочим CI-пайплайном

## 🚀 Флагманский проект

- **[🎬 Интеграционное тестирование API кинотеатра и базы данных](./projects/cinema-ticket-purchase-testing/README.md)**  
Полный цикл ручного тестирования микросервиса с нуля: от проектирования тестовых данных до настройки CI/CD.  

**Что делал как QA:**  
- Спроектировал коллекцию Postman (21 запрос) с динамическими переменными и тестовыми скриптами  
- Провёл ручное тестирование 12 эндпоинтов (клиентские + административные), включая позитивные/негативные сценарии  
- Написал SQL-запросы для проверки целостности данных после операций API (перепродажи, орфанные записи, пересечения сеансов)  
- Разработал smoke-скрипт на bash для быстрой проверки API  
- Настроил CI/CD (GitHub Actions) для автоматического запуска smoke-тестов при каждом push  
- Оформил тестовую документацию: тест-кейсы, тестовая стратегия, наблюдения, документация API  

**Инструменты:** Postman, Docker, PostgreSQL, Flask, Bash, curl, Git, GitHub Actions  
**Роль разработчика:** код приложения написан AI-ментором, моя зона ответственности — качество и тестирование (подробнее в README проекта).
